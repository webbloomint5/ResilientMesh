# ResilientMesh 🛡️🚀

**Author & Architect:** Tiziana Maggio (devlab.solutionstm888@gmail.com)
**Copyright:** © 2026 Tiziana Maggio. All rights reserved.

A production-grade Microservices Mesh built with Node.js, TypeScript, and Express, featuring an API Gateway, real-time health monitoring, proxy routing, and Chaos Engineering.

## Architecture
- API Gateway (Port 4000)
- Auth Service (Port 3001)
- Payment Service (Port 3002)
